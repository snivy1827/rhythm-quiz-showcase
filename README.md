# 多人節奏猜歌遊戲｜作品展示版

從校園活動需求出發，以 AI 輔助開發的多人互動網頁工具。玩家參與節奏挑戰，主持人控制活動進程，投影端呈現遊戲狀態，管理端編輯與發布題庫。

## 我的參與與資料依據

以活動需求與操作流程為出發點，透過 AI 協助產生、修改程式，提供錯誤訊息並進行實測。這是 AI 協作作品，不代表所有程式均由本人獨立手寫。

原版曾用於約 187 人參加的校園活動，這是本人提供的活動規模，並非同時在線人數，也非本展示版的壓力測試結果。

## 功能與技術

- 玩家、主持控制、投影、內容管理與譜面編輯介面。
- Socket.IO 即時事件與遊戲狀態同步。
- 題庫草稿、發布、歷史版本與還原。
- Node.js、Express、本機 JSON 儲存；保留選用 Supabase 同步程式。

上述為原始程式中可查核的實作；驗證範圍請見 VALIDATION.md。

## 快速開始

1. 安裝 Node.js 22 或以上版本。
2. 在本目錄執行 `npm ci`。
3. 執行 `npm start`，開啟 http://localhost:3000 。
4. 開啟 http://localhost:3000/login.html ，首次啟動設定自己的管理員密碼。
5. 登入後開啟 `/manage.html` 檢視示範題庫、`/admin.html` 控制遊戲、`/host.html` 查看投影。
6. 玩家入場資訊請從主持控制介面取得；玩家端可能需要入場 token。

預設僅接受本機連線。若要讓同一可信區域網路的手機參與，可自行將環境變數 HOST 設為 0.0.0.0；先設定密碼，再開放連線。此版本不提供公開網路部署方案。GitHub Pages 無法直接執行此 Node.js 後端。

Supabase 欄位留空即可使用本機模式；可複製 `.env.example` 成 `.env` 設定連接埠。請勿提交 `.env`。

## 外部服務與限制

頁面使用 Google Fonts；QR Code 功能會將加入網址傳給 api.qrserver.com，因此網址中的入場參數也會送至該服務。展示時可略過 QR Code，手動使用本機連結。YouTube 功能僅在設定影片後使用外部播放服務；選用 Supabase 會連線到自行設定的服務。

這是作品審閱與本機展示版本，尚未經完整資安稽核、負載測試或正式部署驗證。移除素材後，原本依賴音檔／圖片的功能需自行加入有權使用的素材。
